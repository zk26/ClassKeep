# 课守 ClassKeep · APP 交互与视觉规范

本文件是项目 UI 规范（技术栈无关的《UI 交互与动效通用规范》）在
Android 教室端上的**落地约定**，供后续改 UI 时对照，避免「加个阴影 / 加个动画」
这类模糊描述重新引入问题。规范原文由项目所有者提供，本文件只记录采纳的条目与实现位置。

实现位置：`mobile/app/src/main/java/top/ikee002/classkeep/UiKit.kt`、
`BottomBar.kt`、`TimetableStore.kt`、`MainActivity.kt`。

---

## 1. 三条硬约束

1. **就地优先**：展开、切换、提交反馈在原位置完成，不跳新页、不整页遮盖。
2. **反馈即时**：内容先上屏，成功后再补状态；不让按钮先转圈挡住结果。
3. **顺序可复现**：动作先后、方向、参数写死，不写「加个动效」。

## 2. 视觉克制（本次重点修复「阴影处理不好」）

| 项 | 约定 | 实现 |
|---|---|---|
| 阴影 | 卡片**不使用 `elevation` / 投影**，只用 1dp 内描边；从外往里最多穿过一层框 | `UiKit.card()` 设 `elevation = 0`，`GradientDrawable` 描边 |
| 同心圆角 | 外层卡片 20dp = 内层控件 14dp + 6dp 缝隙 | `UiKit.shape()` 的 radius 参数 |
| 框内按钮 | 不画边，靠按下时的底色变化提示 | `UiKit.button()` 的 `StateListDrawable` |
| 细线 | 线画在格子内侧；选中变粗不撑大布局 | 课表格 `setMargins(2,2,2,2)` + 固定背景 |
| 品牌头 | 渐变改为纯主色实心块，去掉发灰的投影 | `MainActivity.brandHeader()` |

## 3. 信息常驻

- 浮动标签**常驻输入框上方**（「教师机 IP」「本堂课密钥」「桥接端口」），
  不用会消失的 placeholder。
- 帮助文字**常驻输入框下方**：密钥字段写「与学生机相同；换课后需更新。
  支持手动输入或导入 .key 文件」，端口写「默认 11880，一般无需修改」。
- 上传限制与用途提前写清楚（`ActivityResultContracts.OpenDocument` 前已有说明）。

## 4. 底部标签栏

5 个标签：课堂 / 加分 / 控制 / 课表 / 更多。

- 白色胶囊背景以 `translationX` 平滑跟随选中项（280ms，减速缓动）；
  同时 `scaleX` 走 `1 → 1.12 → 1`，形成「前面先到、后面再跟上」的毛毛虫感。
- 选中项图标 `scaleY` 回弹一次 `1 → .82 → 1.08 → 1`（320ms）。
- 只有选中项长出文字，其余只留单字图标。
- 底栏吸底常驻；`ViewCompat.setOnApplyWindowInsetsListener` 读取手势条高度并加到
  `paddingBottom`，每个页面根容器额外垫高 110dp，列表末尾不会被挡住。

## 5. 加分流程（顺序写死）

```
点学生卡片
  → 弹出 -5…+5（步长 1）列表
  → 选非零分值后弹出原因输入框
  → 确认后【先把新分数上屏】（乐观更新）
  → POST /api/classroom/score
  → 成功保留；失败回滚到原分数并提示
```

禁止：先转圈再显示结果、整页 loading、成功后才更新分数。

## 6. 座位顺序

教师端「Seats & check-in」页的座位卡片可**拖拽互换**，顺序立即写入
`seat-order-<班级>.json`（下次开机不变）。Bridge 的 `/api/classroom/seats`
按该顺序返回学生，APP 的「加分」页据此顺序生成卡片，便于快速点名加分。

## 7. 课表（参考 ClassBoard 但简化）

借鉴「periods + 周一到周日网格、当前节高亮、科目配色」的思路，但不引入
Room / Compose / Retrofit，不复制任何代码或资源：

- 单份 JSON 存 `SharedPreferences`，可导入全校作息 JSON（兼容 periods.times 数组）。
- 今天列高亮、当前节高亮、下一节课提示。
- 点格子就地填写科目，提供常用科目预设，不跳新页。
- 平板上格子更宽、边距更大；课表可横向滚动。

## 8. 平板适配

| 资源限定符 | 页面边距 | 课表格宽 | 学生卡片列数 |
|---|---|---|---|
